For AI assistants

Built for AI assistants.
Friendly to humans.

MCP is the standard plug that lets AI assistants use outside tools. Plug in Motion MCP once, and your assistant can make videos whenever you ask.

  1. 1Sign in to the dashboard and create an API key.
  2. 2Paste this block into your assistant's MCP settings.
  3. 3Ask for a video, in your own words.
mcp.json
{
  "mcpServers": {
    "motion": {
      "type": "http",
      "url": "https://app.studix.digitop.ai/mcp",
      "headers": {
        "Authorization": "Bearer mmcp_YOUR_API_KEY"
      }
    }
  }
}

No assistant? Type your brief straight into the dashboard. Same studio, fewer steps.
