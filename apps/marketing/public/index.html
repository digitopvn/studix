Cho trợ lý AI

Làm cho trợ lý AI.
Thân thiện với con người.

MCP là chuẩn kết nối giúp trợ lý AI dùng được công cụ bên ngoài. Cắm Motion MCP một lần, trợ lý của bạn sẽ làm video bất cứ khi nào bạn cần.

  1. 1Đăng nhập dashboard và tạo một API key.
  2. 2Dán đoạn này vào phần cài đặt MCP của trợ lý.
  3. 3Yêu cầu một video, bằng lời của bạn.
mcp.json
{
  "mcpServers": {
    "motion": {
      "type": "http",
      "url": "https://app.studix.digitop.ai/mcp",
      "headers": {
        "Authorization": "Bearer mmcp_YOUR_API_KEY"
      }
    }
  }
}

Chưa có trợ lý? Gõ brief thẳng vào dashboard. Cùng một studio, ít bước hơn.
